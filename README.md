# RealChatbotAssistant
Architecture & Diagram: How the React 19 frontend communicates securely with the Express API proxy and Google Gemini models.
Prerequisites Checklist: Node.js (v18+), npm, Git, and web browser audio requirements.
Step 1 — Getting the Gemini API Key: Direct walkthrough on obtaining a free API key from Google AI Studio.
Step 2 — Cloning the Repository: Terminal command to clone and navigate into the folder.
Step 3 — Installing Dependencies: npm install breakdown of frontend, backend, and AI SDK packages.
Step 4 — Setting up .env: Commands for Linux, macOS, and Windows to create .env and set GEMINI_API_KEY.
Step 5 — Running Dev Server: How to run npm run dev and open http://localhost:3000.
Step 6 — Feature Walkthrough:
Account Setup: Testing the live 5-rule password checklist and Gmail validator.
Chat Studio: Using Gemini 3.5 Flash, real-time Google Search Grounding with source citations, and Voice mode.
Image Studio: Prompt-based image creation and photo-to-photo editing.
Veo Video Animator: Uploading a photo and generating 16:9 widescreen or 9:16 vertical MP4 video clips.
Themes & Apps: Switching between Warm Espresso, Amber Sand, Sunset Terracotta, and opening the Planner / Usage dashboard.
Step 7 — Production Build & Deployment: Instructions for npm run build, npm start, and cloud hosting (Cloud Run, Docker, VPS).
Step 8 — Troubleshooting Guide: Quick fixes for API keys, microphone permissions, port conflicts, and video generation times.
